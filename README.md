# YOLOv8과 CharCNN 기반 OCR

YOLOv8으로 문자 영역을 탐지하고, 직접 설계하고 학습한 CharCNN으로 문자를 분류한 개인 수업 프로젝트입니다.

## 프로젝트 정보

- 개발자: 이성무
- 진행 기간: 2026.03 ~ 2026.06
- 사용 기술: Python, YOLOv8, CharCNN, EMNIST

## 처리 과정

입력 이미지 → YOLOv8 문자 영역 탐지 → 문자 이미지 추출 → CharCNN 문자 분류 → 예측 결과 표시

## 주요 수행 내용

- Python으로 생성한 폰트 이미지 241장을 활용하여 문자 탐지 모델 초기 학습
- EMNIST ByMerge 47개 클래스를 활용하여 CharCNN 학습
- 인쇄 문자 이미지와 웹캠으로 촬영한 손글씨의 인식 결과 확인
- 문자 영역 탐지 오류와 문자 분류 오류를 구분하여 분석

## 결과 및 오류 분석

인쇄 문자에서 대문자 Y를 M으로, 소문자 q를 숫자 7로 예측하는 등의 오분류가 확인되었습니다.

손글씨에서는 일부 획만 탐지하거나 하나의 문자에 여러 탐지 박스가 생성되는 현상이 나타났습니다. 문자 탐지 누락과 탐지 이후의 오분류도 확인했습니다.

이러한 결과를 바탕으로 다양한 획 두께, 회전, 조명 조건을 반영한 학습 데이터 확장을 개선 방향으로 정리했습니다.
